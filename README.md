# ГП v3 — Discord-бот с командами /gp и управлением матом

**Это новая, постоянно работающая версия**, а не обновление запуска на GitHub Actions. Она меняет название сервера из двух слов «Г» и «П», согласует прилагательное по роду и числу, по желанию публикует торжественный указ, а настройки принимает через Discord slash-команды.

## Важно: что изменилось с v2

- **GitHub Actions не может непрерывно обрабатывать /gp.** Для этой версии `python bot.py` должен работать постоянно на VPS, домашнем компьютере или другом хостинге, поддерживающем длительные процессы и Discord Gateway.
- SQLite в `data/gp.sqlite3` сохраняет параметры и историю между перезапусками. Важно сохранять файл БД на постоянном диске.
- **Старый автоматический GitHub Action нельзя оставлять включённым одновременно с v3**: два процесса начнут независимо менять имя. Новый файл `.github/workflows/daily-rename.yml` убирает расписание и запускает лишь проверки. При обновлении репозитория замените этот файл.
- Этот архив не подключён к вашему Discord, и реальное изменение имени здесь не выполнялось.

## Команды в Discord

| Команда | Эффект | Доступ |
|---|---|---|
| `/gp help` | Список команд | Все |
| `/gp settings` | Время, интервал, канал, мат и следующая дата | Все |
| `/gp stats` | Сколько комбинаций обычных, грубых, матерных | Все |
| `/gp preview count:5` | Случайные названия без изменения сервера | Все |
| `/gp rename` | Немедленное переименование и указ | Управлять сервером |
| `/gp schedule days:3 hour:0 minute:0` | Раз в 3 дня в 00:00 по Москве | Управлять сервером |
| `/gp schedule days:7 hour:18 minute:30 start_date:2026-11-20` | Раз в 7 дней, с заданной даты | Управлять сервером |
| `/gp channel channel:#объявления` | Канал для указа | Управлять сервером |
| `/gp profanity percent:60` | Шанс настоящего мата = 60% | Управлять сервером |
| `/gp announce enabled:true` | Включить/выключить указы | Управлять сервером |
| `/gp enabled enabled:false` | Приостановить расписание, оставив ручные команды | Управлять сервером |

**Чистота словаря и шанс выпадения — разные показатели.** Слова разделены на три уровня: (0) обычные, (1) грубые и вульгарные, но без строгого мата, (2) собственно мат. Команда `/gp profanity` влияет на вероятность выбора **названия из третьей категории**, оставляя во второй массе названий и грубые варианты. По умолчанию задано **45%**. Если поставить 0%, явного мата не будет; при 100% он будет в каждом названии из доступного словаря. Реальный процент на маленькой выборке может отклоняться из-за случайности.

**Важно:** `/gp` — группа команд: нужно набрать `/gp help` или `/gp settings`. Отдельная пустая `/gp` без подкоманды Discord не поддерживается в группе команд.

## Установка (Python 3.12)

1. Обновите файлы репозитория, в том числе `.github/workflows/daily-rename.yml`. Старые `main.py`/скрипт v2 не нужно запускать. Если бот v2 уже работал, выключите его.
2. Создайте/используйте своего бота в https://discord.com/developers/applications . Включите режим установки на сервер с OAuth2 scope `bot` и `applications.commands` (scope `bot` уже может включать регистрацию команд). Выдайте боту **Manage Server / Управлять сервером**, **View Channel / Просматривать канал**, **Send Messages / Отправлять сообщения**. Токен никому не сообщайте.
3. Возьмите числовой ID сервера через режим разработчика в Discord.
4. Установите Python и зависимости:

   ```bash
   python -m venv .venv
   # Linux/macOS:
   .venv/bin/python -m pip install -r requirements.txt
   # Windows (вместо предыдущей строки):
   # .venv\Scripts\python -m pip install -r requirements.txt
   ```
5. Создайте локальный `.env` по образцу `.env.example`. **Это файл переменных окружения, не отправляйте его в GitHub!** Для Linux с systemd файл прочитает `EnvironmentFile`; при ручном запуске сначала экспортируйте переменные:

   ```bash
   export DISCORD_BOT_TOKEN='ВАШ_ТОКЕН'
   export DISCORD_GUILD_ID='ID_СЕРВЕРА'
   # можно указать канал по умолчанию:
   export DISCORD_ANNOUNCE_CHANNEL_ID='ID_КАНАЛА'
   .venv/bin/python bot.py
   ```

### Ручной запуск на Windows (PowerShell)

После установки зависимостей из пункта 4 откройте PowerShell в папке проекта и выполните:

```powershell
$env:DISCORD_BOT_TOKEN="ВАШ_ТОКЕН"
$env:DISCORD_GUILD_ID="ID_СЕРВЕРА"
$env:DISCORD_ANNOUNCE_CHANNEL_ID="ID_КАНАЛА"
.\.venv\Scripts\python.exe bot.py
```

При закрытии консоли или выключении компьютера бот остановится. Для постоянной работы предпочтительнее VPS с `systemd`.

6. После запуска через несколько секунд в вашем сервере должны появиться команды `/gp` (при успешной синхронизации). Выполните `/gp settings`, затем `/gp channel`, `/gp profanity`, `/gp schedule` и `/gp rename`.

По умолчанию: **раз в 3 дня в 00:00 МСК**, начало фазы **17 ноября 2026**, **45% мата**. Если запускаете бот позже, удобнее установить свой цикл с `/gp schedule days:3 hour:0 minute:0` — первая дата цикла автоматически станет ближайшим будущим 00:00 МСК. Часовой пояс расписания сейчас специально фиксирован на Москве.

## Как оставить работающим на VPS

Один раз поместите проект в `/opt/gp`, создайте виртуальное окружение и `.env`, заполните реальные переменные из `.env.example`. Настройте собственные `User` и абсолютные пути в приложенном `gp-bot.service`.

```bash
sudo cp gp-bot.service /etc/systemd/system/gp-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now gp-bot
sudo systemctl status gp-bot
journalctl -u gp-bot -f
```

`Restart=always` запускает процесс после сбоя или перезагрузки сервера. Серверу нужен постоянный интернет. **GitHub сам больше не является хостингом бота.** При бесплатном размещении проверьте, что площадка не выключает спящий процесс и сохраняет SQLite. На своём компьютере он работает только пока компьютер включён и Python-процесс запущен.

## Словари, ограничения и тесты

- Все слова находятся в `words.py`: `G_ADJECTIVES`, `P_NOUNS`, `G_NOUNS`, `P_ADJECTIVES`; внутри уровни 0, 1, 2. У существительных второй элемент — грамматический род (`masc`, `femn`, `neut`, `plur`).
- Генератор из `generator.py` использует `pymorphy3`. Согласование проверяет **форму**, но бессмысленные по смыслу сочетания допустимы специально.
- Название всегда из двух слов; первое на «Г», второе на «П». Подстрока `гей` блокируется. Discord также может отклонить отдельное название своими фильтрами.
- Пауза или отключённые объявления не сбрасывают расписание. Если бот не работал весь день плановой смены, пропущенный день автоматически не компенсируется; при запуске в нужный день после заданного часа бот наверстает пропущенное время в этот же день.
- Если сервер был переименован, но объявление отправить не удалось, в истории сохраняется успешная смена. Двойной смены названия из-за ошибки канала нет.
- Автоматическая проверка выполняется примерно раз в 30 секунд, поэтому это не гарантия 00:00:00.
- Проверки без Discord: `python -m unittest discover -s tests -v`. Для ручного старта `python bot.py`.

## Безопасность

Сменять настройки и переименовывать сервер могут только пользователи с правом Discord **Manage Guild**. Команды просмотра доступны всем. Токен бота должен храниться только в окружении/секретном файле VPS, а не в `README.md`, коде или публичном GitHub. Если токен попадёт в публичный доступ — сразу перевыпустите его в Discord Developer Portal.
